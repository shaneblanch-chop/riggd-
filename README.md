# rigg'd up

Android rigging calculation MVP built with Kotlin and Jetpack Compose.

## Features

- Disclaimer screen
- Dark industrial UI
- Minimum Distance to Lead Block
- Lead Load
- Total Load
- Purchase Head Load
- Lead Block Sling Load
- Glossary
- Metric tons only
- Always rounds up to 2 decimals
- Offline only
- No saved history

## Open in Android Studio

1. Install Android Studio.
2. Open the `riggd-up` folder.
3. Let Gradle sync.
4. Connect an Android phone or use an emulator.
5. Press Run.

## Build APK

In Android Studio:

`Build > Build Bundle(s) / APK(s) > Build APK(s)`

The debug APK will be generated under:

`app/build/outputs/apk/debug/app-debug.apk`
